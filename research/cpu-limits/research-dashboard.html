Key Research Insights
📊
QoS Classes Verified
BestEffort (98.8 ops/s), Burstable (51.3 ops/s), and Guaranteed (51.5 ops/s) behave as expected. Request-only allows bursting when cluster has capacity.
⚠️
Throttling Impact
Phase 4 demonstrates performance degrades proportionally to throttling percentage. Setting aggressive limits reduces performance even with idle cluster CPU.
📈
Production Monitoring
Prometheus + Grafana stack ready to deploy with 7-panel dashboard and 10 alert rules for detecting throttling in production clusters.
🔧
Developer Guidance
Use request-only for most workloads. Set limits only when hard isolation is required. Size limits based on P95-P99 usage, not average.
🎛️
Administrator Toolkit
Complete guide for kernel tuning, custom schedulers (scx), resource quotas, and cluster-level CPU management policies.
🔬
Evidence-Based
16 experiments with structured JSON evidence. All claims backed by cgroup stats, node CPU metrics, and workload performance data.
